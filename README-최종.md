## 운영 메모
- **시연 데이터**: 예약·리뷰·문의·주문 시드는 화면 시연용입니다. D1에는 여러분이 만든 변경분만 저장되므로 섞이지 않습니다. 시드 제거 실운영 스위치는 전환 시점에 넣습니다.
- **긴급 잠금**: 중복 확정이 감지되면 그 슬롯 판매가 자동으로 잠깁니다. 알림·이벤트 → 처리 대기함에서 [해소 · 잠금 해제].
- **권한**: 정책 저장 · 규정 외 환불 · 이의 중 차감 확정 · 원본 반출 · 포인트 조정은 마스터(choi) 전용입니다 (9.7).
